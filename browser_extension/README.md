# z站书单便捷下载浏览器扩展 2.2

在 Edge / Chrome 扩展管理页，加载此文件夹。点击工具栏图标即打开当前网页旁的侧栏，没有本地服务或跳转页面。

自动完整读取并核对书单总数 → 搜索/全选/清洗 → 选择父目录 → 设置启动间隔与同时下载上限 → 下载并生成 Excel。

打开侧栏后自动连续触发原网页“显示更多”。读取数量与 BOOKS / 书籍标签总数一致才提示成功；未读全显示差额，可停止或继续读取。未知总数、超时及数量不一致不会误报读全。

所有文件保存到“父目录 / 书单名称”。书籍使用“书名 - 作者.格式”，同名同大小文件跳过，大小不同保留两份。Excel 离线生成；已有同名 Excel 保留，新导出加编号。

每次按顺序启动一本，两次启动间隔可自由设置，支持 0 和小数秒，无需等前一本完成。可设同时下载上限 1～10 本（默认 1）；满额等待空余名额。侧栏显示每本进度与总速度。

下载期间保持侧栏打开。手动暂停/停止中止在途任务；发生错误暂停新增请求，其他在途任务可完成，随后重试。登录、验证码及网站限额在原网页处理。

权限：activeTab、scripting、downloads、storage、sidePanel；可选网站访问只在下载动作时精确申请，没有 cookies 权限。`z-library.website` 当前文件服务器是 `dln1.ncdn.ec`。

JSZip 3.10.1（MIT）位于 vendor，许可证随包附带。无需 Python、Node、本地服务器或运行时依赖下载。

完整说明与验证范围见 [项目 README](https://github.com/Arthur-Miyano/z-library-booklist-downloader#readme)。
